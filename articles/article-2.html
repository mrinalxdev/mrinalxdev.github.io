Building a Redis-like server from scratch

What happens when you stop using the abstraction and start rebuilding the thing underneath it?

I've been spending a lot of time thinking about what actually happens between calling a method and getting a result back. Most of the time we don't need to care.

That's the whole point of an abstraction.

But every once in a while I find myself wanting to understand what is hiding underneath it. That's usually when I stop using the library and try to build a smaller version myself.

Why build it yourself?

Reading documentation gives you the interface. Reading source code gives you the implementation. Building it yourself gives you the constraints.

Those constraints are usually the interesting part.

You don't really understand a system until you've had to make decisions that the original authors had to make.

Starting with the simplest thing

The first version doesn't need persistence, replication, transactions or clever memory management.

It needs to accept a connection, understand a command and return a response.

server.go
listener, err := net.Listen("tcp", ":6379")
if err != nil {
    log.Fatal(err)
}

for {
    conn, err := listener.Accept()
    if err != nil {
        continue
    }

    go handleConnection(conn)
}

There isn't much here, and that's intentional.

I want every piece of complexity I add later to have a reason for existing.

Then the problems start appearing

A single connection is easy. A thousand connections changes the problem.

  • How should connections be scheduled?
  • What happens when a client is slow?
  • Where does memory get allocated?
  • What happens when the process crashes?
  • How do commands interact with each other?

The interesting part

This is where rebuilding the system becomes more useful than simply reading about it.

You start noticing that the difficult parts aren't necessarily the algorithms. They're the boundaries between things.

There are still a lot of things I don't understand about this. That's probably the reason I'm writing it down.
